# 9. Limits and maturity

The regional model is the production interface. Hex and Global are preview
models; their configuration and checkpoint formats can change. The exact
backend and feature coverage is listed in the [backend guide](../public/BACKENDS.md)
and each model's own documentation.

A feature being selectable or admitted is not, by itself, evidence that it has
been verified against WRF or validated against observations. The physics
reference records the evidence and maturity of individual schemes. The
[verification guide](../public/VERIFICATION.md) distinguishes code comparisons
from observation-based validation.

Memory admission estimates whether a run fits the selected device; it is not
a forecast-quality claim. A successful run also does not establish accuracy
for another location, season, lead time, or physics combination. Use official
meteorological services for forecasts and warnings.
